VaultPass — Offline Password Manager

Completed
Python Tkinter Windows Linux

A fully offline, single-file credential vault for Windows and Linux. Stores passwords, cards, addresses, and images in a portable .vpm file with no cloud account and no network access. Built as a daily-use desktop app for non-technical users.

  • Encrypted at rest with PBKDF2-HMAC-SHA256 (480,000 iterations) and Fernet AES.
  • Autofill HUD detects the active browser window and pastes into the focused field without stealing focus.
  • Clipboard auto-clears after 30 seconds; advanced search supports field filters and AND/OR/NOT.
  • Ships as a single executable (VaultPass.exe / Linux binary) with no Python install required.

custom2fa — Offline TOTP Authenticator

Active
Rust AES-256-GCM Windows Linux

An RFC 6238 TOTP generator that runs entirely on-device. Desktop GUI and CLI share an encrypted .c2fa vault. No cloud, no telemetry, and no network needed to generate codes. Mobile clients are planned; Windows and Linux desktop/CLI ship today.

  • AES-256-GCM vault with PBKDF2; optional OS keychain unlock (Windows Credential Manager).
  • QR and otpauth:// import, encrypted backup/restore, passphrase rotation, and category grouping.
  • Desktop UI: live countdown cards, search, one-click copy with 30-second clipboard clear.
  • CLI covers add/edit/delete/list/code/import/backup for headless or scripted use.

Binary Analyzer

Completed
Python PE / ELF Windows Linux

Static analysis for Windows PE and Linux ELF binaries. CLI and GUI report file type, architecture, imports, strings, Shannon entropy, and a risk score without executing the target. Includes a quarantine workflow for isolating suspicious files.

  • Parses PE/ELF sections and imported functions; scores suspicion from configurable JSON rules.
  • UPX packer detection with optional unpack and before/after comparison.
  • Quarantine: isolate, restore, delete, and export a SHA-256-verified manifest.
  • GUI supports drag-and-drop analysis, click-to-copy hashes, and JSON/text report export; standalone binaries available.

NotesApp — Windows Notes GUI

Completed
Python Windows docx

A Windows desktop app for a structured notes tree (Subjects → Lessons → Notes). Edits .docx files in-app, embeds screenshots, and starts new sessions from templates without hand-managing folders. Built to keep documentation consistent.

  • Tree browser plus Preview / Header / Content / Images / Review / Refs editing tabs.
  • Save overwrites the source .docx with a session backup; images paste from clipboard or disk.
  • New Session copies a master template, fills metadata, and updates the subject lesson map.
  • Filename and full-text search, plus a review-due list for notes past their next review date.

Labs Logbook — Triage Workflow

Active
PowerShell Python Markdown Documentation

A public, structured logbook for malware file triage, with the same slot pipeline used for CTF write-ups, course labs, and threat hunts. No samples are stored — only Markdown, CSV, and screenshots. Demonstrates repeatable documentation and change control.

  • Kind-aware scaffolding (file, ctf, lab, hunt) via PowerShell and a paste-once workflow GUI.
  • Validate, redact-check, and EXIF-strip scripts run before commit; INDEX.md is generated from findings frontmatter.
  • Current public work includes a documented NSIS / fake-alert installer triage with IOCs.
  • Optional workflow_gui binary is the only intended release artifact from the repo.

NexoraLive — Session Rules Platform

In Progress
.NET Windows WebSocket

A larger systems prototype: streamers author plain-text .nle rule files, a shared engine returns Allow / Block / Warn, and a session host admits players through a join gate. Not a production service yet — local demos, Windows tooling, and a growing control plane.

  • Rule language + engine with a simulator so configs can be tested without a live game.
  • Windows session host, hotkey daemon, config editor, and moderation console.
  • Web operator dashboard for join admission, identity checks, and fork catalog prototypes.
  • Useful interview talk-track for documentation, operator UX, and splitting control plane from game runtime.
